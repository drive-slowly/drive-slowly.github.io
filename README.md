# 📈 증시 투자 일기 (배당 성장 기록장)

미국 배당 성장주와 국내 배당주의 배당금 수령 내역을 기록하는 개인 투자 블로그입니다.

👉 **[블로그 바로가기 (증시 투자 일기)](https://drive-slowly.github.io/)**

---

### 💰 주요 기록 종목
* **🇺🇸 미국 직투 (분기 배당):** 아메리칸 익스프레스 (`AXP`)
* **🇰🇷 국내 계좌 (월 배당):** 국내 상장 커버드콜 ETF

### 🛠️ 블로그 구성
* **Engine:** Jekyll (`minima` 테마 커스텀 다크 모드)
* **Font:** Pretendard (Cloudflare CDN 비동기 최적화)
* **Hosting:** GitHub Pages
* **Built with:** Google AI와 함께 디자인 및 최적화 세팅
